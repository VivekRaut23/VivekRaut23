## 🚀 Featured Data Project

### [Retail Sales Analysis (SQL & Power BI)](https://github.com)
Developed an end-to-end analytics solution to clean, explore, and visualize transactional retail sales records. 
* **Data Sanitization & Engineering:** Formatted string transaction records, verified structural data integrity, and safely updated chronological fields to native `DATE` formats using **MySQL**.
* **Advanced Analytical Queries:** Implemented statistical window functions (`RANK() OVER`), Common Table Expressions (CTEs), and complex data aggregation to isolate top-spending customers, track hourly peak time shifts, and isolate high-value transaction parameters.
* **Power BI Dashboards:** Engineered interactive dashboard solutions to visually communicate core insights covering consumer demographic spreads, product category margins, and time-of-day workflow concentrations for stakeholders.
